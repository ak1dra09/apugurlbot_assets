# APUGURL holder bot

Telegram-бот на aiogram 3.x с off-chain балансом, одноразовым snapshot баланса APUGURL через TonAPI и атомарными переводами/drop в SQLite.

## Запуск

1. Установите Python 3.10+.
2. Создайте окружение и установите зависимости:

```powershell
py -3 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

3. Скопируйте `.env.example` в `.env` и укажите `BOT_TOKEN` и `JETTON_MASTER_ADDRESS`.
4. Запустите:

```powershell
python main.py
```

## Команды

- `/start` в личных сообщениях: регистрирует пользователя. Подключение кошелька временно отключено.
- `/balance`: показывает snapshot внутреннего баланса.
- `/send @username сумма` в группе: переводит монеты зарегистрированному пользователю.
- `+fire общая_сумма` в группе: сразу случайно выбирает 10 зарегистрированных пользователей и начисляет им равные доли.
- `/admin_add сумма`: администратор начисляет указанное количество монет на свой баланс.
- `/deposit` в личных сообщениях: показывает адрес кошелька для пополнения и комментарий `DEP<tg_id>`, который обязателен для перевода.
- `/withdraw ADDRESS сумма` в личных сообщениях: создаёт заявку на вывод. Баланс резервируется сразу; администратор получает запрос с кнопками Approve/Reject в личных сообщениях и должен подтвердить перевод, прежде чем бот отправит жетоны в блокчейн.
- `/create_promo NAME uses amount`, `+promo NAME`, `/my_promo` в личных сообщениях: промокоды (см. ниже).

### Пополнение и вывод

Пополнение отслеживается автоматически: фоновая задача каждые `DEPOSIT_POLL_INTERVAL_SECONDS` секунд опрашивает TonAPI на входящие переводы жетона на `DEPOSIT_WALLET_ADDRESS`, ищет в комментарии перевода `DEP<tg_id>` и зачисляет 1 $APUGURL за каждый целый переведённый токен (сумма меньше 1 токена не зачисляется). Обработанные события переводов дедуплицируются по `event_id`, так что повторная обработка невозможна.

Вывод требует отдельного "горячего" кошелька, который реально подписывает и отправляет переводы жетона. Его мнемоника хранится в `HOT_WALLET_MNEMONIC` — заполните её вручную в `.env`, никогда не передавайте в чат. Кошелёк должен быть пополнен TON (для газа) и $APUGURL (для самих выводов). Каждая заявка на вывод ожидает решения администратора; при отклонении или ошибке отправки баланс возвращается пользователю автоматически.

Все внутренние суммы являются целыми числами. Остаток от деления общей суммы на количество победителей не раздается. Telegram Bot API не предоставляет боту полный список участников группы, поэтому выбор идет случайно среди известных боту зарегистрированных пользователей. Создатель rain исключается. Если зарегистрированных пользователей меньше лимита, неразыгранная часть возвращается создателю. Один Telegram ID и один TON-адрес могут быть связаны только один раз. Администраторы задаются через `ADMIN_IDS` и разделяются запятыми.

## TonAPI запрос

```http
GET https://tonapi.io/v2/accounts/<WALLET_ADDRESS>/jettons
Authorization: Bearer <TONAPI_KEY>
```

Код выбирает элемент `balances[]`, у которого `jetton.address` равен `JETTON_MASTER_ADDRESS`, и получает его raw `balance`. Внутренний баланс равен `raw_balance // 100`.

## Ограничения TON Connect

Сессии TonConnect UI хранятся в памяти процесса. Для одного экземпляра бота этого достаточно. При нескольких экземплярах нужен общий storage/Redis. Публичный HTTPS-домен обязателен: обычный `localhost` из Telegram недоступен.
